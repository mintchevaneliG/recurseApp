# recurseApp

I created two different calculators. 

1. Calculator.py holds a calculator that you would just need terminal for. It is a bit wonky and unexpected as you would need to type something like 4 * 4 directly into terminal instead of clicking on buttons as normal. To run this version, please run ```python3 calculator.py```

2. The second calculator is visually much better. It is what we all think of when we say "calculator". Here, I utilized javascript, html and css to create a calculator with bright pink buttons. To run this version, please run ```python3 -m http.server 8000```. Once that successfully runs, please navigate to ```http://localhost:8000/``` . 

For both, you need to have python installed. To check which version is installed, use ```python3 --version```. Otherwise, to install please follow instructions for your specific laptop. An easy way to install it on mac would be to use homebrew.
